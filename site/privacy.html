Privacy, plainly

p2p.video has no company servers in the path of your calls, so there is very little for us to collect. Here is everything that leaves your machines, and where it goes.

This website

  • No cookies, no analytics, no trackers. The site is plain HTML and CSS. Fonts and images are served from this domain; it makes no requests to anyone else.
  • It's hosted on GitHub Pages. Like any web server, GitHub receives your IP address and browser details when you load a page. See GitHub's privacy statement.
  • Downloads come from GitHub Releases, under the same terms.

The app: calls

  • Calls run between your guests' browsers and the host's Mac. There is no p2p.video account and no p2p.video server.
  • To find a direct route, browsers and the host may ask a public STUN server (by default Cloudflare's and Google's) for their own public address. STUN servers see IP addresses, not media. The host can turn public STUN off.
  • When a direct route isn't possible, media is relayed through the TURN relay built into the app, on the host's Mac.
  • Remote access goes through Tailscale, using the host's own Tailscale account. With a public link (Tailscale Funnel), Tailscale forwards encrypted traffic to the host's Mac, and TLS ends on that Mac. Tailscale's privacy policy covers what its coordination service knows about your devices.
  • Chat, raised hands, reactions and the participant list pass through the host's Mac.

The app: recordings, captions and transcripts

  • Nothing is recorded until the host presses Record. Everyone in the call, and anyone waiting to join, is told.
  • Each person's browser records their own camera and microphone, keeps the pieces in that browser's private storage, and uploads them to the host's Mac.
  • Live captions and transcripts are made on the host's Mac with Apple's on-device speech recognition. Audio is not sent to a cloud service for this.
  • Background blur runs on each person's device.
  • A livestream goes only to the destinations the host adds, such as YouTube or Twitch. Stream keys are kept in memory only.
  • Hand-offs to other tools (Minutes, a Parachute vault, a clip editor) happen only when the host asks, and go to tools the host runs.

What we never do

  • No telemetry, crash reporting or usage analytics in the app.
  • No accounts, so no account data to lose or sell.
  • No hosted service that holds your media. When the host deletes a recording from their Mac, it's gone.

If your build of the app includes automatic updates, it checks an update feed over HTTPS. Otherwise you download new versions yourself.

Questions or corrections: open an issue on GitHub. The code is open, so every claim on this page can be checked.
